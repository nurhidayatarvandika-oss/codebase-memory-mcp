
# Codebase Memory MCP

Persistent AI memory server for coding projects.

## Features

- Save project memories
- Search saved memories
- SQLite persistent storage
- MCP integration
- TypeScript implementation

## Installation

```bash
git clone https://github.com/nurhidayatarvandika-oss/codebase-memory-mcp.git

cd codebase-memory-mcp

npm install

npm run build
```

## Run

```bash
npm start
```

## Requirements

- Node.js 20+
- npm
- TypeScript
